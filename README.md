# Samala Srinivas Portfolio

A modern Software Engineer Portfolio built with:

* React.js
* Vite
* Tailwind CSS
* Framer Motion
* React Icons

## Features

* Responsive Design
* Dark Theme
* Animated Sections
* Project Showcase
* Certifications
* GitHub Integration
* Contact Form

## Installation

npm install

npm run dev

## Build

npm run build

## Deployment

Deploy on Vercel:

https://vercel.com
